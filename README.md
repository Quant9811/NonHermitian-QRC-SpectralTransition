 
 Quantum Reservoir Computing for Non-Hermitian Many-Body Localization

This repository contains the code used in the manuscript:

"Quantum Reservoir Computing for Detecting Spectral Phases in a Non-Hermitian Disordered XXZ Spin Chain"

 Contents

1. `non-hermitian_mbl_quantum_reservoir.ipynb` : main reproducible notebook
2. `requirements.txt` : Python dependencies
3. `LICENSE` : MIT license

 Reproducibility

The notebook was tested with:

- Python 3.11
- NumPy
- SciPy
- Matplotlib
- scikit-learn
 

Run the notebook from top to bottom to reproduce all figures and results reported in the paper.
